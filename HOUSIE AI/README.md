# Housie AI 🤖

**Housie AI** is a smart, interactive AI companion powered by **Python Flask**, **SymPy Computer Algebra System**, and **React 18**.

## 🌟 Key Features

- 🧠 **SymPy Math Solver:** Solves derivatives, integrals, quadratic equations, prime factorization, factorials, LCM/GCD, trigonometry, and calculus.
- 📚 **Knowledge Base:** 100+ top mobile & web app definitions (TikTok, WhatsApp, Netflix, ChatGPT, etc.) + 30+ Science/CS concepts.
- 🗣️ **Bilingual AI:** Supports both English and Hinglish seamlessly.
- 😂 **Jokes & Motivation:** 100 curated jokes (English + Hindi) and motivational quotes.
- 🎨 **Minecraft Visual Aesthetics:** React glassmorphic UI overlaying animated canvas drifting clouds, floating robot companion, and custom theme.

## 🚀 Quick Start

### Python Backend (Recommended)

1. Install dependencies:
```bash
pip install flask flask-cors sympy
```

2. Run the server:
```bash
python app.py
```

3. Open `http://localhost:5000` in your browser!

### Node.js Express Backend (Alternative)

```bash
npm install
node server.js
```
